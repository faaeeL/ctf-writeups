Trying to login into bandit26 using the provided private key immediately close the session.

So in order to find out what shell user bandit26 use we need to look for the correct line in the `passwd` file:

```
bandit25@bandit:~$ cat /etc/passwd | grep bandit26                  
bandit26:x:11026:11026:bandit level 26:/home/bandit26:/usr/bin/showtext
bandit25@bandit:~$ cat /usr/bin/showtext
#!/bin/sh

export TERM=linux

exec more ~/text.txt
exit 0
```

So upon entering, it execute the command `more ~/text.txt` then immediately exit.

What we need to do is rescale the window to make it smaller so the text can't be displayed at once:

![image](/pngs/bandit25_26.png)

Then we can press `v` to enter vim and use the command `:set shell=/bin/bash` and then `:shell` to enter the shell

Then we can rescale our window.

```
bandit26@bandit:~$ cat /etc/bandit_pass/bandit26
jHdv2ELQhT22BkprMNDjybZDAkw1zeBJ
```

Upon checking the files we have the file bandit27-do as a `setuid` so we can just grab the password for bandit27 as well.

```
bandit26@bandit:~$ ./bandit27-do cat /etc/bandit_pass/bandit27
STJLJBRRphMxKB392CT4iOr5CbzPU9ER
```

# Notes

The `/etc/passwd` file is a text-based database of information about users that may log into the system or other operating system user identities that own running processes.
